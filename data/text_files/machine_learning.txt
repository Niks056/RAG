Machine learning is a subset of artifical intelligence that enables systems to learn
and improve from experience without being explicitly programmed. It focuses on 
developing computer programs that can access data and use it to learn for themselves

Types of Machine Learning: 

1. Supervised Learning: Learning with labeled data
2. Unsupervised Learning: Finding Patterns in unlabeled data
3. Reinforcement Learning: Learning through reward and penalties


Application include image recognition, speech processing and recommendation systems
